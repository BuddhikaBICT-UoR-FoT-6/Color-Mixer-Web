# Color-Mixer-Web

Last updated: 2026-04-03

## Overview

Color-Mixer-Web is a simple static web project for experimenting with RGB mixing, HEX conversion, and browser-based UI updates.

## Project Goals

- Provide a lightweight, easy-to-understand project structure.
- Separate UI/content files from core logic where possible.
- Keep the codebase simple to run and customize.

## File Structure

- `colors.css`: Stylesheet used by project pages.
- `hex.html`: HTML page for project UI/content.
- `hex.js`: JavaScript logic for interactivity/behavior.
- `history.html`: HTML page for project UI/content.
- `index.html`: HTML page for project UI/content.
- `mixer.js`: JavaScript logic for interactivity/behavior.

## Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Open `hex.html` or `history.html` in your browser.

## Development Notes

- This project is designed for learning and small-scale experimentation.
- Edit source files directly and test changes incrementally.
- Keep reusable logic grouped in utility/helper files.

## Customization Ideas
